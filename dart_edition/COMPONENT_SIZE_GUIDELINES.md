# 元件尺寸規範

這是本專案的尺寸設定，單位為 Flutter 邏輯像素（dp）。共用尺寸由 `lib/ui_library/control_size.dart` 的 `AppControlSize` 管理，間距由 `lib/ui_library/spacing.dart` 的 `AppSpacing` 管理；淺色與深色使用相同尺寸。

| 元件 | 預設尺寸與規則 |
| --- | --- |
| Filled／Outlined／Elevated／Text／Segmented 按鈕 | 最小寬 64、高 40；內距左右 24、上下 8；寬度隨文字增長 |
| IconButton | 最小 40 × 40；一般圖示 24；清單操作圖示 20；密集排列仍保留點擊區 |
| 文字輸入、下拉輸入 | 最小高 40；內距左右 12、上下 8；前後圖示區至少 40 × 40；多行、提示及錯誤文字可增加高度 |
| 下拉選項 | 每列最小高 48（Flutter 下拉元件限制）；選單最大高 320，超出可捲動 |
| 自動完成選項 | 最大高 240；無可用寬度限制時寬 320，否則跟隨輸入欄寬度 |
| 清單列、表格列 | 最小高 40；可隨文字及欄位增高；表格儲存格內距 12，尾端操作欄寬 40 |
| Material DataTable | 表頭高 40；資料列最小高 40、內容可增高；左右邊距 16、欄間距 24 |
| Chip | 圖示建議 18；外內距左右 8、上下 4；可互動 Chip 保留 Material 的 padded 點擊區 |
| AppControlChip | 用於 IP／Port 等與操作列並排的狀態；可見框線與按鈕、欄位等高；內距依文字行高與描邊計算 |
| AppBar | 工具列高 64（不含系統安全區） |
| NavigationBar／NavigationRail | 導覽列高 80；側邊導覽最小寬 80 |
| FAB | 一般 56 × 56、小型 40 × 40、大型 96 × 96；點擊區保留 padded 設定 |
| 區塊卡片／頁面 | 區塊內距 24；可用寬度小於 600 時頁面內距 16，否則 24；區塊間距 16 |
| CollectionPanel | 預設高度範圍 192–320；清單內距 8；底部內容間距 12；可依用途傳入高度 |
| AppDialog | 內容最大寬 520；畫面邊距水平 40、垂直 24；內容內距左右 24、上 20；可依用途覆寫 |
| 空狀態／通知 | 空狀態圖示一般 48、緊湊 32；通知圖示一般 24、緊湊 20；通知內距 12 |

## 間距與縮放

- 間距階梯為 **4、8、12、16、24、32**；元件內小間距用 4／8，欄位間距用 12／16，區塊內距用 16／24。
- 單行控制項最小高度為 `max(40, ceil(16 + 24 × 字級 / 14))`。整數化避免字型排版取整造成框線與按鈕差 1dp。字級 14／16／20 分別對應 40／44／51dp。
- 表單依實際文字行高計算垂直內距，下拉框另外考慮 Flutter dense 控制項的內容高度；比較的是可見框線高度。`AppTextField`、`AppDropdownField`、`AppControlChip` 與共用表格列也反映系統文字縮放。
- 高度使用最小限制，不以固定高度裁切多行輸入、錯誤訊息或放大的文字。容器寬度由父層可用空間決定；長標籤應換行或提供可辨識的省略與 tooltip。
- 互動圖示的尺寸與點擊區分開考慮。一般圖示按鈕保留 40 × 40 的互動區；按鈕明確使用 `shrinkWrap`，避免 Material 自動補成 48dp。避免以負密度或頁面固定尺寸進一步壓縮共用元件。
- 一般 Icon 預設從全域 `iconTheme` 取得 24 dp 尺寸與 `ColorScheme.onSurface` 顏色，隨明暗主題及自訂主題色更新，避免只設定尺寸而回退為黑色。清單、按鈕、語意狀態及特殊容器可使用其對應前景色；色票上的黑白圖示依色票亮度選取對比色。
- 自訂圖表畫布、時間軸節點與正文編輯區可使用專用尺寸；共用控制項則優先引用上述常數。特殊覆寫需由元件參數明確表達用途。

## 適用範圍

規範已套用到 AppTheme 與 UI Library 的共用表單、操作列、表格、卡片、集合、通知及對話框預設值。頁面中的個別明確尺寸覆寫仍需依其用途判斷，不能假設會被全域主題強制覆蓋。

清單列與清單卡片的視覺、文字及互動配置另依 [List、ListCard 顯示規範](LIST_DISPLAY_GUIDELINES.md)。`AppListCard` 內距左右 12、上下 8 dp；列間距 8 dp，最小高 40 dp，內容與操作可增高；可用寬度小於 320 dp 時尾端操作移到內容下方。
